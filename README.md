# 자료구조 구현 (Data Structures in C/C++)

C 기반 지식을 바탕으로 선형·비선형 자료구조를 밑바닥부터 직접 구현한 학습 기록입니다.
단순히 라이브러리를 사용하는 것을 넘어, 내부 동작 원리를 이해하기 위해 각 자료구조를
직접 설계하고 구현했습니다. 데이터 엔지니어링 진로와 연결되는 지점을 함께 정리했습니다.

## 개발 환경

- **OS**: Windows 11 + WSL2 (Ubuntu)
- **언어**: C / C++
- **컴파일러**: g++
- **빌드**: `g++ main.cpp src/*.cpp -I include -o test`

## 구현 목록

### 1. 이중 연결 리스트 (Double Linked List) — C
선형 자료구조의 기초. 노드 간 양방향 포인터 연결과 삽입·삭제 시
포인터 재배치를 직접 구현하며 메모리 관리 감각을 익혔습니다.

- 양방향 노드 연결 (prev / next)
- 삽입·삭제 시 포인터 재배치
- **핵심**: 포인터와 동적 메모리 관리의 기초

### 2. 해시테이블 (Hash Table) — C++
키를 해시 함수로 변환해 상수 시간에 접근하는 자료구조.
충돌 처리와 동적 리사이즈를 직접 구현했습니다.

- 체이닝(분리 연결법)으로 충돌 처리
- 부하율(load factor) 기반 리사이즈 + 재해싱
- CRUD (insert / search / remove)
- **핵심**: O(1) 평균 접근의 원리와 충돌 처리
- **연결**: DB 인덱스에서 단일 키 조회가 빠른 이유

### 3. 이진탐색트리 (Binary Search Tree) — C++
좌소우대(왼쪽은 작고 오른쪽은 큰) 규칙으로 정렬을 유지하는 트리.
재귀를 활용한 구현에 집중했습니다.

- 재귀 기반 insert / search
- 순회 3종: 전위 · 중위 · 후위 (DFS)
- 레벨 순회 (BFS, 큐 활용)
- 소멸자: 후위 순회로 안전한 메모리 해제 (자식 먼저, 부모 나중)
- **핵심**: 재귀적 사고, 중위 순회 = 정렬된 출력
- **연결**: 중위 순회 = DB의 ORDER BY 원리 / B-Tree 인덱스의 조상

### 4. 그래프 (Graph) — C++
정점과 간선으로 관계를 표현하는 비선형 자료구조.
표현부터 순회, 위상 정렬까지 구현했습니다.

- 인접 리스트(adjacency list) 표현
- DFS (재귀 + visited 배열로 사이클 대비)
- BFS (큐 + visited)
- 위상 정렬 (Kahn's algorithm) + 사이클 감지
- 방어적 프로그래밍: 잘못된 정점 입력 검사
- **핵심**: DFS/BFS의 차이, 진입차수 기반 위상 정렬
- **연결**: 위상 정렬 = Airflow DAG의 실행 순서 결정 엔진의 실체

## 프로젝트를 통해 배운 것

- **재귀적 사고**: 트리 순회와 그래프 DFS를 재귀로 구현하며 "종료 조건 + 자기 호출" 패턴 체화
- **자료구조 간 트레이드오프**: 해시(빠른 단일 조회) vs 트리(범위·정렬 조회)의 용도 차이
- **메모리 관리**: 소멸자에서 후위 순회로 해제하는 이유 (부모를 먼저 지우면 자식이 미아가 됨)
- **방어적 프로그래밍**: 예상치 못한 입력이 전체를 멈추게 하지 않도록 경계 검사
- **진로 연결**: 위상 정렬이 데이터 파이프라인(Airflow DAG) 스케줄링의 핵심 원리임을 확인

└── main.cpp    # 테스트 코드
